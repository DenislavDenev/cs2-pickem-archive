# CS2 Pick'em Archive

Public, human-readable archive of locked model predictions and final outcomes for every CS2 Major.

Predictions are generated by a private probabilistic model before each Swiss stage begins. Once a stage starts, prediction files are immutable -- what you see is exactly what the model said before the first match was played.

## Immutable Update Policy

- **Prediction files** (`prediction.md`, `prediction.json`) are updated freely before stage start, then locked permanently at `stage_start_at`. No edits after that point.
- **Outcome files** (`final-outcome.md`, `final-outcome.json`) are written exactly once after all teams in a stage have a terminal record. Never overwritten.
- **Retroactive files** carry an explicit RETROACTIVE banner and are exempt from the lock rules above -- they are reproducible calibration artifacts, not predictions.
- **Screenshots** are added manually before stage start and are never touched by automation.

## Data Boundary

This repo contains only derived model outputs: recommendations, per-team probabilities, sanitized decision metrics, final standings, scorecards, and calibration scores.

**Never published here:** DAGs, scraper code, raw match rows, player rows, roster rows, raw market history, BigQuery staging tables, credentials.

See [DATA_BOUNDARY.md](./DATA_BOUNDARY.md) for the full list.
